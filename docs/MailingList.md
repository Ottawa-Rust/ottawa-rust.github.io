# Mailing list

We decided to use a mailing list for discussion rather than Zulip/Discord/Slack/etc.   This is a small group so traffic should be very light.   We can revisit if traffic gets heavy, which we do not anticipate.

There are three mailing lists:

- **[join@ottawa-rust.ca](mailto:join@ottawa-rust.ca)**: general discussion about Rust
- **[join-meta@ottawa-rust.ca](mailto:join-meta@ottawa-rust.ca)**: help plan events
- **[join-announcements@ottawa-rust.ca](mailto:join-announcements@ottawa-rust.ca)**: receive announcements of future events

To join, send a blank email to one of the above addresses and reply to the subsequent confirmation request.

For questions email [admin@ottawa-rust.ca](mailto:admin@ottawa-rust.ca).

## Leaving

Every message carries an unsubscribe link in its footer, so you can
leave at any time.
