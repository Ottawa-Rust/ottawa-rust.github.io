# Optimizing Rust Binary Size for Fun

**Thursday, November 26, 2026 · 6:00 PM – 9:00 PM EST**

A Rust "Hello, world" in a default release build is 439 KB. The same
program in C is 14 KB. This talk starts with a short ELF primer to show
what fills that space. Then it uses compiler and profile settings and
feature flags to make a real-world binary 90% smaller. It ends with
`no_std` tricks that get Hello World to 1.9 KB, and with the settings to
use in production.
