# Writing crates that support async and blocking

**Thursday, October 15, 2026 · 6:30 PM – 8:30 PM EDT**

If you're writing a library crate, you have to decide whether you want
an API that's async or blocking, or both. Jason Walton covers different
strategies for handling async and blocking, and what common pitfalls you
might run into.
