# Introduction

Bienvenue sur le site Web du groupe de rencontre linguistique Ottawa Rust.

Nous nous intéressons au langage puissant et sûr Rust. Nous nous rencontrerons occasionnellement pour partager des connaissances et des idées, discuter et apprendre Rust et contribuer à des projets. Les personnes de tous niveaux sont les bienvenues, même si vous êtes simplement curieux de connaître la langue !

Rust est un langage de programmation système qui s'exécute à une vitesse fulgurante, évite presque tous les plantages et élimine les courses aux données. Les fonctionnalités de Rust incluent les types de données algébriques, la correspondance de modèles, les fermetures, l'inférence de type, les abstractions sans coût, la sécurité de la mémoire garantie, le garbage collection facultatif, la concurrence sans courses de données, un temps d'exécution minimal, la prise en charge des plates-formes embarquées et des liaisons C efficaces.

Apprenez-en plus sur Rust sur https://www.rust-lang.org/
